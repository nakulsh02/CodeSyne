## ✨ Key Features

- ⚡ **Multi-Language Runtime Engine**: Instant zero-latency compilation & execution for JavaScript, TypeScript, Python, C++, Java, Rust, Go, HTML/CSS, and SQL.
- 👥 **Real-Time Multiplayer Collaboration**: Instant room-based pair programming with live multi-cursor tracking, shared file systems, and synchronized terminal streams.
- 🤖 **AI Assistant & Code Intelligence**: Built-in context-aware AI coding companion for real-time refactoring, intelligent auto-completion, and instant bug detection.
- 🎨 **Monaco Editor Core**: Powered by the industry-standard Monaco editor engine with full syntax highlighting, bracket matching, code folding, and custom themes.
- 💻 **Ultra-Lightweight Desktop Shell**: Built with Tauri and Rust — consumes less than 25 MB RAM and starts up instantly on Windows 7, 8, 10, and 11.
- 📱 **Adaptive Android Client**: Full touch-optimized layout, swipe gestures, and virtual keyboard ergonomics.

## 🖥️ System Requirements

### Windows
- **OS**: Windows 7 SP1 (with WebView2 Runtime) / Windows 8.1 / Windows 10 / Windows 11 (Both 32-bit and 64-bit supported)
- **RAM**: Minimum 512 MB, Recommended 2 GB+
- **Disk Space**: ~25 MB free space

### Android
- **OS Version**: Android 8.0 (API 26) or newer
- **Permissions**: Internet access (for cloud compilation and sync)

## 🔒 Security & Privacy

CodeSyne utilizes client-side sandboxing and secure encrypted communication channels. All code executions in collaboration sessions run in isolated environments to protect your system integrity.
