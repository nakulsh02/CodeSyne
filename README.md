## ✨ Key Features

### ⚡ Instant Multi-Language Execution
- Compile and run code in **Python, JavaScript, TypeScript, C++, Java, Rust, Go, HTML/CSS, and SQL** in milliseconds.
- Interactive terminal stream with real-time `stdin` inputs and syntax-highlighted error logs.

### 👥 Real-Time Multiplayer Collaboration
- Instant room-based pair programming with zero complex setup.
- Synchronized multi-cursor tracking, shared file tree, and real-time team chat.

### 🤖 AI-Powered Intelligence
- Integrated context-aware AI companion for instant code explanation, refactoring, and automated bug fixing.
- Generates clean, production-ready boilerplates on demand.

### 🎨 Industry-Standard Monaco Editor
- Full IntelliSense, code auto-completion, parameter hints, bracket pair colorization, and customizable dark/light themes.

### 💻 Native Lightweight Runtimes
- **Desktop (Windows 7/8/10/11)**: Powered by Rust and Tauri with hardware acceleration and zero memory bloat (<25 MB total footprint).
- **Mobile (Android)**: Full mobile-responsive touch layout with adaptive virtual keyboard support.

## 🖥️ System Requirements

### Windows Requirements
- **OS**: Windows 7 SP1 / Windows 8.1 / Windows 10 / Windows 11 (Both 32-bit and 64-bit supported).
- *Note for Windows 7 users*: Requires Microsoft WebView2 Runtime.
- **RAM**: 512 MB minimum (2 GB recommended).
- **Disk Space**: ~25 MB free space.

### Android Requirements
- **OS**: Android 8.0 (API Level 26) or higher.
- **Permissions**: Internet access (for cloud compilation and collaboration sync).

## 🔒 Security & Sandboxing

CodeSyne utilizes strict sandboxed isolation for all code executions. Workspace collaborations run via encrypted WebSocket pipelines to ensure your system and network remain 100% secure.
